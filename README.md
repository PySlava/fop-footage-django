# 🏢 ФОП Кадри

Веб-система для автоматизації кадрового обліку, розрахунку заробітної плати, формування податкової звітності та фінансової аналітики для ФОП-роботодавців.

---

## 🚀 Основний функціонал

* **Мульті-ФОП та Кадровий облік**: Ведення обліку декількох суб'єктів господарювання (ФОП) та профілів їхніх працівників.
* **Кадровий документообіг**: Автоматична генерація наказів про прийняття на роботу, звільнення та відпустки у форматі **PDF**.
* **Облік часу та Зарплата**:
  * Інтерактивне ведення табеля обліку робочого часу (`TimesheetDay`).
  * Автоматичний розрахунок середнього заробітку для відпускних та лікарняних.
  * Розрахунок заробітної плати (Gross / Net) з розбивкою за утримуваними податками (ПДФО 18%, ВЗ 5%, ЄСВ 22%).
  * Генерація та завантаження персональних розрахункових листків (PDF).
* **Звітність ДПС**:
  * Автоматична генерація **XML-повідомлень** про прийняття працівника на роботу для подачі в ДПС.
  * Формування звітів у форматах Word та Excel.
* **Аналітичний дашборд**:
  * **Фінансовий моніторинг**: Помісячні графіки витрат на фонд оплати праці (ФОП) та податкового навантаження (Chart.js).
  * **Графік відпусток**: Візуальний інтерактивний календар відпусток та відсутностей співробітників (FullCalendar.js).

---

## 🛠 Технології

* **Backend**: Python 3.12+, Django 6.1.1
* **Database**: PostgreSQL / SQLite (для dev-середовища)
* **Frontend**: HTML5, Bootstrap 5, Bootstrap Icons, Chart.js, FullCalendar.js
* **Генерація документів**: PDF (ReportLab / WeasyPrint), Word (python-docx), Excel (openpyxl), XML (xml.etree)

## 🔧 Локальне розгортання

1. **Клонувати репозиторій:**
   ```bash
   git clone [https://github.com/PySlava/fop-footage-django.git](https://github.com/PySlava/fop-footage-django.git)
   cd fop-footage-django

2. **Створити та активувати venv:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # macOS / Linux
    #venv\Scripts\activate   # Windows
   
3. Встановити залежності:
    ```bash
    pip install -r requirements.txt

4. Налаштувати .env:
   Створіть файл .env на основі .env.example та заповніть необхідні параметри.

5. Виконати міграції:
   ```bash
   python manage.py migrate

6. Запустити сервер розробки:
   ```bash
   python manage.py runserver

Система буде доступна за адресою: http://127.0.0.1:8000/
